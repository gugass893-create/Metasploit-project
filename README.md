# Metasploit-project (проект лаборатории кибербезопасности)
Этот проект был выполнен в рамках курса «Безопасность информационных систем» Международном греческом университете (факультет информационной и электронной инженерии).

Это учебное тестирование на проникновение с использованием виртуальной машины Metasploit.Цель - отработать методы тестирования на проникновение в безопасной контролируемой среде.
