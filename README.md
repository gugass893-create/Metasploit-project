# Metasploit-project (проект лаборатории кибербезопасности)
Этот проект был выполнен в рамках курса «Безопасность информационных систем» 

Это учебное тестирование на проникновение с использованием виртуальной машины Metasploit.Цель - отработать методы тестирования на проникновение в безопасной контролируемой среде.


🎯**Цели**
---

1) Практика в тестировании на проникновение в виртуальной лаборатории среде (metasploit).
2) Применяйте такие методы, как разведка, эксплуатация уязвимостей и повышение привилегий.
3) Зафиксируйте процесс в отчете о тестировании на проникновение.


🛠️**Используемые инструменты**
---

⦿ Kali linux

⦿ nmap

⦿ metasploit-framework (msfconsole)

⦿ set RHOSTS, show info, exploit
